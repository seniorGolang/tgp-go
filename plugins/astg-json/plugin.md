# Плагин astg-json

## Назначение

Плагин **astg-json** выводит полную модель проекта (контракты, методы, типы, аннотации), которую строит плагин **astg**, в формате JSON — в stdout или в файл. Это удобно для отладки, инспекции того, как инструмент «увидел» проект, а также для интеграции с внешними инструментами.

Команда: `tg astg json`.

## Когда это полезно

- Нужно посмотреть модель проекта целиком в JSON, не запуская генерацию кода.
- Нужно выгрузить модель конкретной сохранённой версии из локальной базы контрактов.
- Нужно передать модель во внешний инструмент (через stdout или файл).

## Использование

```bash
# Текущий проект (разбор исходников из ./contracts) → stdout
tg astg json

# Текущий проект → файл
tg astg json -o .tg/project.json

# Конкретная версия из локальной базы контрактов → stdout
tg astg json --from-db myapi@v1.0.1

# Последняя сохранённая версия проекта из базы
tg astg json --from-db myapi

# Интерактивный выбор проекта@версии из базы
tg astg json --from-db
```

## Опции

| Опция            | Тип    | Описание |
|------------------|--------|----------|
| `out` (`-o`)     | строка | Путь к выходному файлу. Если не задан — вывод в stdout. |
| `contracts-dir`  | строка | Путь к папке с контрактами для разбора текущего проекта (по умолчанию `contracts`). |
| `all-contracts`  | bool   | Загружать из базы полную модель без интерактивного выбора контрактов (по умолчанию `true`). |

Опция `from-db` подключается плагином **astg-db** (загрузка модели из локальной базы контрактов). Формат ссылки — см. документацию astg-db (`tg plugin doc astg-db`).

## Источник модели

- **Без `from-db`** — модель строит плагин **astg** из исходников (или берёт из кэша).
- **С `from-db`** — модель загружает из локальной базы плагин **astg-db**; при `all-contracts=true` выгружается полная модель без интерактивного выбора контрактов.

## Зависимости

В пайплайне должен быть подключён плагин **astg**. Для загрузки из базы дополнительно используется **astg-db**.

## Skill для агентов

Пакетный skill `tgp-astg-json` — экспорт и интерпретация resolved-модели (поиск контрактов по семейству transport, чтение аннотаций/типов через `typeID`, сравнение local vs DB). После установки пакета: `tg pkg skills install`.
